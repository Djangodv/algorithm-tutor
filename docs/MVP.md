# Minimum Viable Product (MVP)

1. A diagram (flowchart) explaining the structure of the code
2. Instructions for running the project locally
3. A working web page using the Svelte framework 
4. A web page hosted on Github pages that's accessible from the web
5. A Python web interpreter built using Pyodide
6. A simple animation for visualizing Python lists using D3.js
7. A Github repository where the source code is hosted
8. Start button for executing Python code and playing the visualization
